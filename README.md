### About Me

I moved into software from an Electrical & Electronics Engineering background, and that switch still shapes how I work — I like taking a system apart, understanding every layer, and then rebuilding it better. Today that shows up as two parallel tracks: **native Android development** (Java + Kotlin, on-device ML, Firebase) and **Java full-stack web development** (Spring Boot/Spring MVC, Hibernate/JPA, JDBC, MySQL). I build most of my projects independently end-to-end — architecture, backend, UI, and release.

**What I'm working on right now:**
- 🤖 On-device ML in Android — TFLite inference for real-time notification classification
- 🔥 Firebase-backed production apps — auth, Firestore, Cloud Functions, subscription/payment flows
- 🔁 Modernizing a legacy Java web stack end-to-end — plain JDBC → Hibernate → Spring MVC → Spring Boot 3 / Java 17
- ⚙️ Android automation via AccessibilityService
